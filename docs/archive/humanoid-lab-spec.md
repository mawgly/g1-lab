# Лаборатория Humanoid — согласованное направление

Дата: 19 октября 2026. Пользователь подтвердил реализацию схемы из чата.

Первый эксперимент сохраняется без изменения моделей как baseline с отдельным отчётом. Новые эксперименты имеют неизменяемые конфигурации, собственные каталоги и очередь последовательного выполнения. Управление через локальный браузер: список, создание по пресетам, запуск/остановка, диагностика, отчёт, сравнение графиков и независимый просмотр лучших/последних моделей.

Ускорение: изолированная среда MuJoCo Warp на NVIDIA; сначала фактическая проверка совместимости, конечности значений и скорости 128/256/512/1024 сред. GPU и CPU результаты сравниваются на одной CPU-среде Humanoid-v5 с одинаковыми тестовыми seeds. Отчёт явно отделяет исходные пять попыток от новой проверки30попыток. Ускорение физики не обещает качество ходьбы. Сеть/копирование данных входят в реальные ограничения.

Настройки: CPU baseline PPO lr3e-4, rollouts1024x8, batch256, epochs10, gamma.99, gae.95, entropy0, clip.2, net256x256, log_std_init-1; нормализация obs/reward. Новый запуск сохраняет полный конфиг и версии. Пресеты baseline, осторожное обновление и исследование; seeds42/43/44; сохранять каждые500000шагов и при остановке. При GPU выбирать число сред отдельно, сохранить общее число переходов на обновление в разумных пределах. Старую модель можно копировать в новое продолжение без изменения исходника.

Отчёт: настройки, источники, версии/неизвестные исторические значения, метрики, лучший/последний, графики, история сессий, ограничения и гипотезы отдельно от фактов. Не заполнять отсутствующие компоненты награды выдуманными историческими данными.

Безопасность исполнения: один тяжёлый job одновременно, очередь хранится на диске, восстановление после перезапуска не начинает работу самопроизвольно. Остановка сохраняет модель; ночной запрет сна привязан к процессу. Только localhost и проверенные experiment IDs/параметры, никаких произвольных команд/путей из HTTP.

Проверки: тесты конфигов/очереди/сохранения/HTTP, настоящее короткое обучение CPU/GPU, диагностика baseline, браузерный обход действий и отсутствие JSошибок. Не запускать многочасовую серию без необходимости проверки: очередь коротких исследований доступна пользователю.
