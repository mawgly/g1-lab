# Глоссарий перевода: русский → English → 中文

Термины лаборатории для перевода интерфейса, дневника, имён веток и заметок. `humanoid_sim.journal_translate`
вставляет эту таблицу в каждую пачку для переводчика (`.claude/agents/lab-translator.md`), а интерфейсные каталоги
`humanoid_sim/web/i18n/en.json` и `zh.json` держатся тех же слов. Новое слово — новая строка таблицы (четыре столбца,
разделитель `|`); в столбцах перевода через `/` идут варианты для перечисленных через `/` русских слов.

Слова латиницей (`exp-…`, идентификаторы вроде `feet_flat`, имена файлов, PPO, GPU, MuJoCo, Unitree, G1, seed,
sim2sim, FixStand) не переводятся. Единицы после чисел — символами: m, s, m/s, rad/s, mm, N, N·m; «млн шагов» → M.
